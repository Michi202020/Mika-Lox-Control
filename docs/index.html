Mika Lox Control – Firmware-Installer

Firmware direkt aus dem Browser auf dein Gerät spielen – ohne zusätzliche Software.

Benötigt Chrome, Edge oder Firefox (ab Version 151) auf dem Desktop, eine HTTPS-Verbindung (bereits gegeben) sowie ein echtes USB-Datenkabel (kein reines Ladekabel). Safari, iOS und Chrome/Firefox für Android werden aktuell nicht unterstützt.

1. Gerät auswählen und verbinden

Wähle unten dein Gerätemodell, verbinde es per USB und folge den Anweisungen im Popup.

4848S040CIY1 Version 1.0.2
Dein Browser unterstützt das leider nicht. Diese Seite muss über HTTPS laufen.
4848S040CIY3 Version 1.0.2
Dein Browser unterstützt das leider nicht. Diese Seite muss über HTTPS laufen.
Waveshare ESP32-S3-LCD-4 (Rev4) Version 1.0.2
Dein Browser unterstützt das leider nicht. Diese Seite muss über HTTPS laufen.

2. Hinweise zur Verbindung

  • Im Geräte-Popup kann dein ESP32 als "USB JTAG/serial debug unit", "CP210x USB to UART Bridge", "CH340" oder ähnlich erscheinen – das ist normal, einfach auswählen.
  • Stelle sicher, dass kein anderes Programm (z. B. Arduino IDE, PlatformIO Monitor) gerade auf den USB-Port zugreift.
  • Nach erfolgreichem Flashen startet das Gerät automatisch neu.

3. Nach dem Flashen: Aktivierung

Beim ersten Start zeigt das Display eine Chip-ID und einen Freischaltcode an. Wie du daraus deinen persönlichen Aktivierungscode bekommst, steht in der Repository-README.
